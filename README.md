# ТИХО · Київ — Android alarm v10.0

## Новое: пробуждение, когда появился свет

Кнопка «Разбудить меня, когда включат свет» включает отдельное одноразовое ожидание нового Telegram-уведомления из канала [СвітлоБот — Здановської 52/3, під'їзди 3 та 4](https://t.me/svitlobot_lom52_3).

Когда Telegram показывает уведомление этого канала с сообщением `🟢 12:29 Світло з'явилося`, ТИХО проверяет городской статус воздушной тревоги (API Київ Цифровий). Только при **подтверждённом отбое** воспроизводится выбранная мелодия и вибрация. При активной тревоге или недоступном API приложение повторяет проверку приблизительно раз в минуту; Android может задерживать фоновые проверки.

**Настройка:** в ТИХО включить режим, разрешить доступ к уведомлениям и точные будильники. В Telegram подписаться на указанный канал, не выключать его уведомления, разрешить предпросмотр текста. На Xiaomi/POCO/HyperOS разрешить Telegram и ТИХО работать в фоне; выключение оптимизации батареи повышает надёжность, но не гарантирует доставку.

Приложение локально читает Android-уведомления Telegram — **не входит в аккаунт**, не просит пароль и никуда не отправляет тексты. Оно фильтрует отправителя по названию канала и словам «СвітлоБот», «Здановської», «52/3»; Telegram не передаёт стабильный идентификатор канала через Android-уведомление. По этой причине название и предпросмотр должны быть видны; неподходящее или сгруппированное уведомление может не сработать.

Режим **одноразовый**: после сигнала автоматически отключается; не звонит, если электричество уже было при нажатии кнопки, пока не придёт следующее сообщение. Работает отдельно от обычного будильника по времени. При перезагрузке телефона ожидание света сохраняется, но до появления нового уведомления приложение не знает о фактическом состоянии электричества.

**Ограничение:** если Telegram не получил уведомление или Android ограничил фоновую работу, звонка не будет. Если важно не проспать, установите запасной системный будильник. Сервис не отключает официальные уведомления о воздушной тревоге и сирены.

## Сохранённые функции v9

Будильник по часам/минутам, дни недели, 4 мелодии и системные звуки, регулировка громкости, вибрация, отложить на 5/10/15 мин, автоматическое восстановление расписания после перезагрузки. В режиме «Ждать подтверждённого отбоя» при активной тревоге или недоступном API не звонит, повторяет проверку ориентировочно через 60 секунд.

Городской статус проверяется через https://kyiv.digital/open-api/air-alert/state . Это не аварийное приложение, его нельзя использовать вместо официального предупреждения об опасности.
